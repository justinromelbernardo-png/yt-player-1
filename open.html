Help
Where is the portal file on my phone?
  1. Sent in Messenger, Telegram or Viber: tap the file, then Save or Download. On iPhone or iPad choose Save to Files.
  2. From Google Drive or Gmail: tap the file → ⋮ → Download (Android) or Open in → Save to Files (iPhone, iPad).
  3. Then tap Choose the portal file above. Look in Downloads (Android) or Browse → On My iPhone / Downloads (iPhone, iPad). The file ends in .html.
Why not just tap the file?

Phones show a downloaded web page as a preview that doesn't run its buttons, so the portal can't sign you in there. This page opens the same file properly, in your browser.

Your instructor sent a new version

Choose the new file the same way. It replaces the old copy here; your notes, settings and progress stay. Then you can delete the downloaded file.

Add this page to your home screen
  1. iPhone or iPad (Safari): Share → Add to Home Screen → Add.
  2. Android (Chrome): ⋮ → Add to Home screen.
  3. Open your portals from that icon from now on — it works offline too.

On a computer you don't need this page: double-click the portal file to open it in your browser.
